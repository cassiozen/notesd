# Settings

Settings has the same categories, in the same order, on every app. They're in two groups: settings
**synced to your account**, which every device signed in to it shares, and settings for **this
device only**. An app leaves out a category or row it has nothing for.

At the top, the account row shows who you're signed in as, and on which server. It opens
**Server**.

| Category | What's there | Kept |
| --- | --- | --- |
| **Server** | The server address; sign in, connect or sign out. On the web: the server's version, [updating it](../self-hosting/upgrading.md#updating-from-settings) (admins), and changing your account password | Account |
| **Security** | The lock password for [locked notes](locked-notes.md): create, lock now, change, reset. Passkeys (web), fingerprint (Android) or Face ID (iPhone) unlock. On the web: the browsers and devices signed in to your account | Account; fingerprint and Face ID on this phone only |
| **Spaces** | Create, rename, change the icon of, and delete [spaces](organize-and-find.md#spaces) | Account |
| **Integrations** | [Email](email.md) through Resend. Only admins can change it | The whole server |
| **Appearance** | Theme: system, light or dark. On the web, the note font too | This device |
| **Sync & data** | On the web: [keep notes on this device](offline-and-sync.md#the-web-app), and install the app. On the phones: sync status (iPhone) and removing all data from the device | This device |
| **About** | The app's version (phones only) | This device |

To change your account password from a phone, use the web app. If you've forgotten it, the
server's admin [resets it](../self-hosting/users.md#adding-people).
