# Introduction

notesd is a notes app you host yourself: your notes live on a server you control.
It's one single binary to deploy with everything built in, and no stack of services to look after.

You use it from the browser or the Android, iPhone and Mac apps that work fully offline and sync when they can reach the server.

## What you need

**A server:** a 64-bit Linux machine (x86-64 or ARM64) or an Apple silicon Mac. Any of these works:

- **A machine you own**, such as a Raspberry Pi or a mini PC.
- **A VPS** like Hetzner or DigitalOcean, usually $4–6 a month.
- **A VM platform** like Fly.io, the cheapest and least work: about $2–3 a month, with HTTPS included.
