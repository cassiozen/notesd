# 3. Write your first note

## Write

1. Click **New note** at the top of the list.
2. Type a title, press Return, and write something:

   ```text
   Pancakes

   2 eggs, 1 cup flour, 1 cup milk. Rest the batter for 10 minutes.
   ```

The first line of a note is always its title. There's no Save button: notes save as you type.

To format text, use the formatting bar: bold, italic and strikethrough, a check list, indenting,
links and pictures. **Text styles** (**Aa**) holds headings, quotes, and bulleted and numbered
lists.

## Tag

Add a tag anywhere in the title or text by typing `#` and a name (tags aren't picked up inside
links or code):

```text
#recipes #breakfast
```

Some tag forms:

| Write | For |
| --- | --- |
| `#recipes` | A one-word tag |
| `#home/garden` | A tag nested under `#home` |
| `#to read#` | A tag with spaces, closed with a second `#` |

The sidebar lists every tag you use (if it's hidden, click **Show sidebar** above the list).
Click one to show only its notes. A parent tag such as `#home` also shows the notes tagged
`#home/garden`.

## Search

Type in **Search all notes** above the list. Search covers titles and text, matches the
beginning of words (`panc` finds "Pancakes"). When the match is in a note's text, the result
shows the text around it.

- **Enter** opens the first result.
- **Escape** clears the search.
